iOS
Main app OpenBackup for iPhone Available now Apple App Store

Install on your iPhone

Download OpenBackup from the App Store and connect it to the same cloud source as your Mac.

  1. Open the App Store on your iPhone.
  2. Search for OpenBackup.
  3. Tap Get and wait for the download to complete.
  4. Open OpenBackup and follow the on-screen introduction.
  5. Choose the same cloud connection that you configured with OpenBackup Setup on your Mac.
  6. Test the connection and open the dashboard to view your SuperDuper! backup status.

Required Mac setup OpenBackup Setup for macOS Supports SD4 from version 4.0.6 and SuperDuper! Classic Download OpenBackup 2.3 (build 21)

Install on your Mac

The configuration wizard does not open automatically after installation.

  1. Download OpenBackup.pkg.
  2. Open the package and complete the installation. An administrator password or Touch ID is normal and is required to install the software in the Applications folder.
  3. When the installation is complete, click Close. The configuration wizard does not open automatically.
  4. Open Finder by clicking the blue-and-white face in the Dock. Then click Apps in the sidebar and double-click OpenBackup. or Click the blue-and-white Finder icon in the Dock. Then press Shift + ⌘ + A to open the folder containing your installed apps. Double-click OpenBackup.
  5. The OpenBackup Setup configuration wizard opens.
  6. Follow the five steps in the configuration wizard. Choose SuperDuper! 4 (version 4.0.6 or later) or SuperDuper! Classic and select the preferred status folder.
  7. Complete the configuration and connect the OpenBackup app on your iPhone or Android phone.

Installation guides

Set up each part in the right order.

Start with SuperDuper! on the Mac, run OpenBackup Setup, connect your status location and finish on iPhone or Android.

Status connection

OpenBackup mobile app

Install OpenBackup on iPhone or Android and test the connection.
1 Prepare SuperDuper! ⌄
  1. Create each backup job in SuperDuper! 4 (version 4.0.6 or later) or SuperDuper! Classic and choose the correct source and destination.
  2. Run every job once manually and verify that it finishes successfully.
  3. Give each job a clear, unique name so it is easy to recognize in OpenBackup.
2 Configure OpenBackup on macOS ⌄
  1. Download and install OpenBackup Setup.
  2. Open OpenBackup Setup from the Applications folder.
  3. Choose SuperDuper! 4 (version 4.0.6 or later) or SuperDuper! Classic, select the status folder and complete activation.
3 Connect the status location ⌄
  1. Choose a locally synchronized Google Drive or Dropbox folder, or a folder published through your HTTPS server.
  2. Make sure the OpenBackup status reaches that location successfully.
  3. Select the same connection in the OpenBackup app on your phone.
4 Install and connect the mobile app ⌄
  1. Install OpenBackup from the App Store on iPhone or Google Play on Android.
  2. Open Settings and select Google Drive, Dropbox or Custom Server (HTTPS).
  3. Grant the requested access and tap Test connection.
  4. Return to the dashboard and refresh the backup status.
